**Tipo:** Individual

**Tema oficial:** U1·AE1 Generalidades de los sistemas distribuidos, capas de software y arquitectura, Modelo Cliente-Servidor.

**Prerrequisitos:** ninguno (semana de arranque).

**Actividad:** investigación guiada + diagrama de capas de software y arquitectura de un sistema distribuido real, identificando el modelo cliente-servidor en el proyecto CECyT9 (frontend en Vercel ↔ backend en Render ↔ base de datos en Supabase).

**Entregable:** diagrama de arquitectura cliente-servidor del sistema CECyT9 (quién es cliente, quién es servidor, qué protocolo usan) + reporte de una cuartilla.
