# Semana 12 (9-13 nov) — Distribuidos

**Tipo:** Individual

**Tema oficial:** U3·AE2 continúa: XML, invocación de servicios SOAP, servicios WSDL, localización de servicios UDDI.

**Objetivo:** invocar un servicio SOAP/WSDL público (ejercicio aislado) para entender XML/SOAP antes de decidir cómo evoluciona la API propia.

**Prerrequisitos:** semana 11.

**Actividad:** consumir un servicio SOAP público de ejemplo (ej. conversor de divisas o clima) con una librería cliente SOAP; inspeccionar el XML de petición/respuesta.

**Entregable:** script que invoca el servicio SOAP + XML de petición/respuesta anotado, explicando por qué la industria migró hacia REST/WebSocket.

**Archivo base:** `base/consumir-soap.js` (andamiaje, complétalo tú). Servicio SOAP público sugerido: `https://www.dataaccess.com/webservicesserver/NumberConversion.wso` (operación `NumberToWords`).
